# Hugh Fletcher Photography

A responsive photography portfolio website built for GitHub Pages.

## Website files

- `index.html` — main portfolio page
- `style.css` — visual design and responsive layout
- `script.js` — image lightbox and dynamic footer year
- `images/` — your photography files

## Required photo filenames

Upload the photographs using these exact names:

`01.jpg` through `12.jpg`

`01.jpg` is used as the large hero image at the top of the website.

## GitHub Pages

In the repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select the `main` branch and `/ (root)`, then save.

GitHub Pages may take a few minutes to publish after the first deployment.

## Before publishing

Replace `YOUR-EMAIL@example.com` in `index.html` with the email address you want visitors to use, if desired.
